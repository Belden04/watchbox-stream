# Portflix Streams

Build a premium streaming platform called PORTFLIX using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL (XAMPP).

The website focuses on Movies (Translated & Non-Translated) and Sports Highlights only (no live matches).

Design a world-class UI inspired by Netflix, Disney+, Prime Video, ESPN, and MasterClass, with a unique identity using Black, Orange, Green, and White colors. Add smooth animations, glassmorphism, modern cards, page transitions, hover effects, loading animations, and fully responsive layouts.
